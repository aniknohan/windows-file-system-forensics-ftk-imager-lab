# NTFS Forensic Analysis Screenshots

This directory contains screenshots documenting the forensic examination of the NTFS laboratory volume using Exterro FTK Imager.

These screenshots support the forensic analysis documented in:

`docs/04-ntfs-forensic-analysis.md`

## Examination Scope

The screenshots in this directory demonstrate:

- Identification of the NTFS partition in FTK Imager.
- Examination of the NTFS file-system structure.
- Identification of active files.
- Examination of intentionally deleted file artifacts.
- Review of NTFS metadata and file properties.
- Examination of hexadecimal data where relevant.
- Review of unallocated space and recoverable forensic artifacts.

## Evidence Source

The NTFS laboratory volume was examined as:

`\\.\PHYSICALDRIVE1`

The volume was identified as:

`NTFS_LAB [NTFS]`

The screenshots provide visual evidence of the NTFS forensic examination performed during the laboratory.
