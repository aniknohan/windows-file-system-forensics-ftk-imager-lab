# FAT16 Forensic Analysis Screenshots

This directory contains screenshots documenting the forensic examination of the FAT16 laboratory volume using Exterro FTK Imager.

These screenshots support the forensic analysis documented in:

`docs/06-fat16-forensic-analysis.md`

## Examination Scope

The screenshots in this directory demonstrate:

- Identification of the FAT16 partition in FTK Imager.
- Examination of the FAT16 file-system structure.
- Identification of active files.
- Examination of intentionally deleted file artifacts.
- Review of file metadata and file contents.
- Examination of unallocated space where relevant.

## Evidence Source

The FAT16 laboratory volume was examined as a physical-drive evidence source in FTK Imager.

The screenshots provide visual evidence of the FAT16 forensic examination performed during the laboratory.
